# Yu Production Hub

一个运行在本机的 ComfyUI 创作台，把图片生成、改图、短视频与 H3 有声视频工作流集中到同一页面。网页可以不开 ComfyUI 前端，但本机 ComfyUI 后台仍需运行。

生成队列会保留任务状态，并提供“查看结果”“打开文件夹”和“原地删除”。“原地删除”只隐藏 Hub 中的任务索引，不删除 ComfyUI 历史或硬盘里的生成文件。

## 已包含的公开示例

- Kontext 双图改图
- SDXL 日常出图
- SVD 图片转短视频
- MiniMax H3 文字生成有声视频
- MiniMax H3 图片生成有声视频

公开仓库不包含模型、私人工作流、生成作品或作者电脑的绝对路径。模型及第三方节点须遵守各自的许可证。

## 启动

1. 安装 Node.js 18 或更新版本。
2. 将 `config.example.json` 复制为 `config.local.json`，填写自己的 ComfyUI 路径。
3. 确认工作流所需模型已经放到 ComfyUI 的模型目录。页面只显示当前后台能够验证通过的卡片。
4. 双击 `启动网站.cmd`，或运行 `node launcher.cjs`。
5. 浏览器打开 <http://127.0.0.1:8900>。

如果已经手动启动 ComfyUI，主后台使用 8188 端口，H3 后台使用 8189 端口，此时可以只保留 URL 配置。

## H3 低显存说明

H3 示例采用 320×512、124 帧、20 步的本机低显存预设，并通过独立的 8189 后台运行。它会生成带音轨的 MP4；提示词可以写动作、环境声与对白。8GB 显存设备仍可能需要较长时间，并依赖足够的系统内存与虚拟内存。

## 数据与安全

服务只监听 `127.0.0.1`。上传素材、任务记录和作品都留在本机。`config.local.json`、日志和运行目录已加入 `.gitignore`。
